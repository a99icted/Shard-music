# Shard 0.1.10 — проверка дубликатов при скачивании

Теперь при скачивании музыки с YouTube, Spotify и Яндекс Музыки Shard проверяет, есть ли треки в библиотеке, и предлагает использовать имеющиеся записи вместо новых копий. Предупреждения и выбор действий работают так же, как при синхронизации устройств.

## Что нового

- В окне «Добавить музыку» появились настройки «Предупреждать о дубликатах» и «Игнорировать дубликаты». Они сохраняются отдельно от настроек синхронизации. По умолчанию предупреждения включены, а автоматическое игнорирование выключено.
- При обнаружении совпадений можно скачать копию или пропустить дубликат. Выберите действие для каждого трека либо включите «Применить ко всем найденным дубликатам».
- Проверяются уже сохранённые треки и повторы внутри скачиваемого плейлиста. До скачивания совпадения определяются по ссылке на источник либо по названию, исполнителю и длительности с допуском 3 секунды.
- После скачивания и перед импортом выполняется дополнительная проверка метаданных и содержимого файла. Это помогает обнаружить совпадения, которые нельзя было определить заранее.
- При пропуске дубликата имеющийся трек добавляется в новый плейлист без создания ещё одной копии аудио. Записи с отсутствующим аудиофайлом не переиспользуются.
- Если предупреждения выключены, настройка «Игнорировать дубликаты» определяет поведение автоматически: использовать имеющиеся треки или скачивать новые копии.
- Отмена проверки останавливает текущую загрузку и позволяет очереди продолжиться. Уже сохранённые треки остаются в библиотеке. В отчёте загрузки отдельно показано количество треков, использованных без новых копий.

## Установка и обновление

Для **Windows 10 (2004+) / Windows 11 x64** скачайте `Shard-0.1.10-Setup-x64.exe`.

Установщик включает компоненты загрузки музыки; отдельно устанавливать Rust, Node.js или FFmpeg не нужно. Музыка, плейлисты и настройки сохраняются при обновлении. После публикации стабильного релиза обновление станет доступно через приложение в версиях с поддержкой автообновлений.

Этот выпуск относится к Windows. Версия Android-приложения не изменена.

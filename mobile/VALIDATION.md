# Проверка Android 0.1.1 — 15 ноября 2026

Среда: Android 15 / API 35, x86_64, эмулятор Pixel 6 с размером экрана
720 × 1280 и плотностью 320 dpi (360 dp по ширине).

Проверено на реальном Android runtime:

- Главная открывается на плейлистах; доступны избранное и все треки.
- Настройки открываются отдельно; оформление, загрузки и статистика показывают
  только содержимое своей вкладки. Возврат в библиотеку работает.
- Общий Rust/JNI импортирует WAV, создаёт плейлист, добавляет трек в избранное,
  меняет метаданные и удаляет только данные, созданные тестом.
- Android MediaSession декодирует импортированный файл, начинает воспроизведение,
  принимает перемотку и паузу. Тест запускает Activity перед запросом аудиофокуса,
  как требует Android 15 для первоначального воспроизведения.
- Загрузчик обновляется через официальный stable endpoint до **2026.10.26**.
- Сетевой instrumentation-тест скачал аудио пятисекундной публичной записи
  `gHKT4uU8Zng` из актуальных тестов yt-dlp; файл проверен и удалён тестом.
- Через обычный интерфейс вставлена та же ссылка и нажата кнопка скачивания:
  WorkManager скачал M4A, Rust добавил его в библиотеку; итоговый отчёт
  «Добавлено: 1 из 1. Ошибок: 0.».

Unit-тесты: 4 проверки, включая сочетание старого предупреждения/SABR/HTTP 403
и ограничение длинного русского отчёта по размеру UTF-8 для WorkManager.
Полный запуск AndroidJUnitRunner с включённым сетевым тестом: **OK (4 tests)**.
Android Lint: 0 ошибок; предупреждения касаются доступных новых версий зависимостей.

Это проверка на эмуляторе, а не измерение энергопотребления физического телефона.
Обновления загрузчика не выполняются при запуске или локальном прослушивании.
Проверки и повторные попытки ограничены; кеш подписей переиспользуется.
Доступность конкретных записей, ограничения аккаунта/региона и работа конкретной
сети YouTube остаются внешними условиями.

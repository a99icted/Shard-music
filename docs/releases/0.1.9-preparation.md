# Подготовка Shard 0.1.9 для Windows

Хотфикс импорта Spotify подготовлен 25 ноября 2026 года.

- Рекомендуемый тег: `v0.1.9`.
- Название: **Shard 0.1.9 — хотфикс импорта Spotify**.
- Сообщение коммита: [0.1.9-commit.txt](0.1.9-commit.txt).
- Описание релиза: [v0.1.9.md](v0.1.9.md).

## Артефакты

Файлы для публикации находятся в `dist` и не добавляются в Git:

- `Shard-0.1.9-Setup-x64.exe`;
- `Shard-0.1.9-Setup-x64.exe.sha256`;
- `Shard-0.1.9-manifest.json`;
- `Shard-0.1.9-verification.json`.

Размер установщика: **152 401 182 байта**. SHA-256:

```text
2022121706a943e59258479c831a5c956d865c56d51b52babb456c02eb67d499
```

`scripts/package-windows.ps1` собрал release-версию с оптимизацией.
`scripts/verify-windows-package.ps1 -Version 0.1.9` успешно сверил все 888
файлов payload, обязательные компоненты, контрольные суммы, соответствие
release-бинарнику, AMD64, ресурс приложения 0.1.9.0 и версию установщика 0.1.9.
Личные данные не включены. Запуск установки не выполнялся.

## Проверка исправлений

- Общий последовательный прогон библиотеки: 80 тестов прошли, 5 сетевых/внешних тестов штатно пропущены.
- Сетевой тест метаданных запущен отдельно: получены 505 доступных треков из 509 позиций плейлиста, альбомы на 8 и 31 трек, включая страницы по 7 треков; изображения альбомов загружены и декодированы.
- Сетевой тест реального скачивания запущен отдельно: `Zachz Winner — doodle` из плейлиста и `MORGENSHTERN — Красный Флаг - Acoustic Live` из альбома скачаны во временные каталоги; выбор и чтение обложек проверены.
- Пользователь подтвердил работу debug-сборки с исправлениями.
- `cargo check --locked`, `cargo fmt --all -- --check` и `git diff --check` прошли при подготовке исправлений.

Версия общей Rust-библиотеки и Windows-установщика поднята до 0.1.9.
`mobile/native/Cargo.lock` синхронизирован с общей библиотекой и новыми
зависимостями; версия Android-приложения не изменена, APK не собирался.

После подготовки индекса сообщение коммита можно использовать так:

```powershell
git commit -F docs/releases/0.1.9-commit.txt
```

Коммит, тег и публикация релиза не выполнялись.

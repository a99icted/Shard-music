# Shard 0.1.6 / Android 0.1.8 — игнор треков, обложки и устройства

В этом выпуске игнор треков, получение обложек и вкладка подключённых устройств
доступны на Windows и Android. Обновлены интерфейс Windows, работа с библиотекой
и хранилищем. Текущая синхронизация — ручная передача музыки по локальной сети;
live-управление плеером в этот выпуск не входит.

## Игнор треков

- Пункт «Игнорировать трек» в меню ⋯ и значок запрета рядом с полосой перемотки.
- Треки с плашкой «Игнор» остаются в общей библиотеке и плейлистах, но не попадают
  в обычную очередь, перемешивание, автопродолжение и повторы.
- Игнорируемый трек можно запустить напрямую для разового прослушивания.
- Добавление текущего трека в игнор сразу переключает воспроизведение.
- Игнор снимает избранное; снятие игнора не восстанавливает его автоматически.
- В «Настройки → Игнорирование» можно послушать трек, снять игнор крестиком,
  удалить файл или удалить все игнорируемые треки с подтверждением.

## Обложки и библиотека

- Обложки из тегов аудиофайлов, превью YouTube и метаданных Spotify / Яндекс Музыки.
- Автоматические обложки плейлистов; вручную выбранная картинка имеет приоритет.
- Получение недостающих обложек старой библиотеки без повторной загрузки аудио,
  с возможностью отмены: «Хранилище» на Windows, «Оформление» на Android.
- На Android обложки отображаются в списках, плеере и системной медиасессии.
- На Windows превью создаются в фоне, не блокируя открытие библиотеки.
  Повреждённая картинка не задерживает остальные треки; кэш изображений ограничен.

## Windows

- Обновлены логотип, иконки, главная страница и навигация; «Избранное» закреплено
  рядом со «Все треки», боковую панель можно свернуть.
- Три режима: по порядку, перемешивание, перемешивание с автопродолжением.
  Переключение режима само по себе не запускает музыку.
- Последовательная очередь загрузок с отменой текущей задачи, удалением ожидающих
  ссылок и отчётами. Уже сохранённые треки остаются после остановки задачи.
- Объединение двух плейлистов в новый с сохранением исходных подборок.
- Настройки хранилища: открытие папки, перенос с проверкой базы и сохранением
  исходной копии, очистка музыки с подтверждением. Настройки, статистика
  и оформление пустых плейлистов сохраняются.

## LAN-синхронизация и Android

- Вкладка «Подключённые устройства» появляется при включённой синхронизации:
  имя, UUID, адрес, версия протокола, ручная отправка библиотеки и прогресс.
- Исправлено сопряжение через точки доступа телефона и ПК: QR содержит
  альтернативные локальные адреса, обратный адрес берётся из соединения.
- Android использует общие с Windows Rust-сервисы для библиотеки, игнора,
  обложек и передачи музыки. После получения данных библиотека обновляется.

**Границы текущей синхронизации:** протокол v2 передаёт аудио, плейлисты
и добавление в избранное, поддерживает дубликаты и возобновление передачи.
Игнор, снятие избранного, удаления, внешние обложки, фоны, настройки
и статистика не зеркалируются. Обложки внутри аудиофайла передаются вместе с ним.
Вкладка устройств показывает одно сопряжение текущего сеанса;
после перезапуска синхронизации нужно подключиться заново.

Live-управление воспроизведением, фантомы треков, автоматический обмен действиями
и статистика по устройствам пока только спроектированы и в этих сборках
**не реализованы**.

## Скачать

| Устройство | Файл |
| --- | --- |
| Windows 10 (2004+) / Windows 11, x64 | `Shard-0.1.6-Setup-x64.exe` |
| Android 8.0+, телефоны ARM64 | `Shard-Android-0.1.8-arm64-v8a.apk` |
| Android 8.0+, x86_64 | `Shard-Android-0.1.8-x86_64.apk` |

Windows-установщик включает yt-dlp, FFmpeg, ffprobe, Node.js и библиотеки Visual C++.
Отдельная установка этих компонентов не нужна.

Android APK — оптимизированные release-сборки с текущей development-подписью
проекта для установки вне магазина. Для обновления поверх прежней копии
нужен совпадающий ключ подписи. Android versionCode: 9.

К каждому файлу приложена контрольная сумма `.sha256`.

## Проверки

- Rust: 68 unit-тестов и 17 интеграционных тестов прошли; 2 сетевых теста пропущены.
- Android: 14 unit-тестов и 12 instrumentation-тестов на Android 15 прошли;
  1 сетевой тест пропущен. Lint: 0 ошибок, 10 предупреждений о версиях зависимостей.
- Подписанный release APK x86_64 установлен и запущен на эмуляторе.
  ARM64 APK собран и проверен без запуска на физическом телефоне.
- Windows: прошли проверки воспроизведения, игнора, загрузки библиотеки
  со 180 обложками и кэша изображений. Проверены все 884 файла установщика,
  версии, архитектура x64 и SHA-256.

Установка Windows поверх пользовательской копии и передача между физическим
телефоном и ПК в этом прогоне не выполнялись. Визуальная проверка окна Windows
была недоступна из-за таймаута инструмента; автоматические проверки пройдены.

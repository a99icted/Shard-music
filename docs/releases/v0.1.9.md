# Shard 0.1.9 — хотфикс импорта Spotify

Исправлен импорт больших плейлистов Spotify: приложение могло получать только часть списка, например 98 треков вместо более 500. Теперь плейлисты и альбомы загружаются постранично с проверкой полного списка. Если Spotify не отдаёт очередную страницу, импорт сообщает об ошибке вместо успешного завершения с обрезанным списком.

- Треки из Spotify-плейлистов получают собственные обложки из Spotify. Если обложка отсутствует или не загружается, используется превью найденного видео YouTube.
- Обложка плейлиста применяется к самой коллекции и больше не подставляется всем её трекам.
- При импорте альбомов обложка альбома по-прежнему применяется к трекам.
- Для импорта по ссылке не нужны аккаунт Spotify, API-ключ или установленный spotDL.

Изменение обложек применяется к новым загрузкам; ранее сохранённые изображения автоматически не заменяются. Недоступные позиции, для которых Spotify скрывает метаданные, могут быть пропущены. Возможность скачать аудио зависит от доступности подходящего совпадения на YouTube.

Проверено получение 505 доступных треков из плейлиста на 509 позиций и полных альбомов на 8 и 31 трек, включая переход между страницами. Отдельно проверены реальные загрузки трека из плейлиста и трека из альбома с соответствующими обложками.

Для Windows 10 (2004+) / Windows 11 x64 скачайте `Shard-0.1.9-Setup-x64.exe`. После публикации стабильного релиза пользователи 0.1.8 смогут установить обновление через приложение. Музыка, плейлисты и настройки сохраняются при обновлении.

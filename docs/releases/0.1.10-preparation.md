## Артефакты

Файлы для публикации находятся в `dist` и не добавляются в Git:

- `Shard-0.1.10-Setup-x64.exe`;
- `Shard-0.1.10-Setup-x64.exe.sha256`;
- `Shard-0.1.10-manifest.json`;
- `Shard-0.1.10-verification.json`.

Размер установщика: **152 789 528 байт** (145,71 МиБ). SHA-256:

```text
088f981ad9fa71f74250152ce3478e441cc6ff6b13defa7c08f4188d427e0117
```

Пакет содержит release-приложение, yt-dlp, FFmpeg, ffprobe, Node.js, библиотеки Visual C++ и лицензии зависимостей. Личная библиотека и настройки не включены.

Сборка и проверка выполняются штатными скриптами:

```powershell
.\scripts\package-windows.ps1
.\scripts\verify-windows-package.ps1 -Version 0.1.10
.\scripts\test-windows-updater.ps1
```

## Проверки

- При реализации проверка всех целей `cargo check --locked --all-targets` и ручная проверка общего диалога и настроек загрузки выполнены на изолированной временной библиотеке.
- При подготовке установщика изолированный тест обновления прошёл: ожидание завершения старого процесса, тихая установка, автоматический перезапуск, обновление работающего приложения из трея, корректное завершение с сохранением состояния. Посторонняя копия и внешние данные не изменялись.
- Повторный прогон на версии `0.1.10`: `cargo test --locked --no-default-features --lib --test library -- --test-threads=1` — 89 модульных и 17 интеграционных тестов прошли, ошибок нет; 5 тестов с внешними сервисами штатно пропущены.
- `cargo fmt --all -- --check` и `git diff --check` прошли.
- Повторная проверка всех целей на версии `0.1.10`: `cargo check --locked --all-targets` прошла. Компилятор сообщает существующие предупреждения зависимостей GPUI и proc-macro-error2; ошибок сборки нет.
- `scripts/package-windows.ps1` успешно собрал оптимизированный release и установщик. `scripts/verify-windows-package.ps1 -Version 0.1.10` сверил все 888 файлов payload, хеши, обязательные компоненты, соответствие собранному release-бинарнику, архитектуру AMD64, ресурс приложения `0.1.10.0` и версию установщика `0.1.10`.
- Готовый установщик не запускался поверх пользовательской копии. Проверка установки и перезапуска выполнена отдельно штатным скриптом на изолированном тестовом приложении с другим AppId. Отчёт: `dist/windows-updater-smoke-verification.json`.

Версия общей Rust-библиотеки и установщика Windows — `0.1.10`. Оба Cargo lock-файла синхронизированы. Версия Android-приложения не менялась, APK не собирался.

Коммит, тег, push и публикация релиза не выполнялись.

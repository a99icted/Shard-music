Вложения релиза:

- `Shard-0.1.7-Setup-x64.exe`;
- `Shard-0.1.7-Setup-x64.exe.sha256`;

- `Shard-0.1.7-verification.json`.

Версия Cargo и ресурс установщика обновлены до 0.1.7. Запись общей Rust-библиотеки в `mobile/native/Cargo.lock` синхронизирована с Cargo.toml. Версия самого Android-приложения сохранена; новая мобильная сборка не входит в этот выпуск.

Коммит должен включать исходники, новые модули аудио и интерфейса, PNG-атласы в `assets/pets`, скрипты подготовки рисунков, примеры проверок, Cargo.toml, Cargo.lock, installer/shard.iss и документацию. Выходные файлы `dist`, `target`, скачанные инструменты и личные данные остаются вне Git.

После проверки и подготовки индекса сообщение можно использовать командой:

```powershell
git commit -F docs/releases/0.1.7-commit.txt
```

Коммит, тег и публикация релиза автоматически не выполнялись.

Проверка упаковки сверяет SHA-256 всех файлов staging, состав компонентов, версии и архитектуру исполняемых файлов, соответствие release-сборки и контрольную сумму установщика. Установка поверх пользовательского приложения не выполняется.

- Машинный отчёт: `dist/Shard-0.1.7-verification.json`.

Проверки при подготовке 0.1.7:

- `cargo check --offline --all-targets` — успешно.
- Тесты библиотеки с desktop: 75 прошли в общем запуске, один тест остановки LAN-передачи завершился по тайм-ауту и прошёл при отдельном повторе; три теста пропущены штатно.
- `cargo test --locked --bin shard -- --test-threads=1` — 12 прошли, два аппаратных теста пропущены штатно. Первоначальный запуск теста PCM-потока завершился разрывом соединения; отдельный повтор и повтор всего набора прошли.
- `cargo test --locked --no-default-features --lib --test library -- --test-threads=1` — 68 тестов библиотеки и 17 интеграционных тестов прошли; два сетевых теста пропущены штатно.
- `cargo fmt --all -- --check` и `git diff --check` — успешно.
- `cargo test --locked --all-targets` не завершён: запущенный пользовательский `target/debug/shard.exe` блокирует перезапись бинарника. Приложение не завершалось; использованы отдельные команды выше.

Тесты приложения и GPUI-проверки покрывают восстановление аудиовыхода, очередь, перемотку, локальный поток, анимированные фоны, геометрию прогресс-бара, направления питомцев и отсутствие перерисовок библиотеки от анимаций. Репорт о пропадании звука после трёх часов не проверялся непрерывным трёхчасовым сеансом; используются сценарии восстановления и проверки аудиотракта. Захват локального потока проверялся через FFmpeg; сквозная проверка с OBS не выполнялась.

# Shard 0.1.8

- Windows update checks now use the stable releases of a99icted/Shard-music on GitHub. A notice below Settings offers Update and Don't show again. The notification preference is saved between launches.
- Settings → Updates shows the installed version, a manual Check for updates button, a notification toggle and a Download update button.
- Updating requires confirmation. Shard downloads the installer, checks its size and SHA-256, then exits normally. The installer waits for Shard to finish, updates the same installation and opens Shard again. Music, playlists and settings are preserved.
- The settings category Window and performance is now named Performance.
- The Windows installer now exits a running Shard gracefully before replacing files, including 0.1.7 with active playback or a hidden tray window. Ordinary window closing could previously leave Shard running and block the update.
- Spotify requests respect the Windows system proxy, retry temporary HTTP 502/503/504 failures, and report embed error pages more precisely.

The automatic updater is introduced in this version. Install 0.1.8 manually once; subsequent stable versions can be installed from inside the app. Download `Shard-0.1.8-Setup-x64.exe` for Windows 10 (2004+) / Windows 11 x64.
